# Security Policy

## Supported Versions

We actively maintain and provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The **MCP Server Security Auditor** team takes the security of our software and the broader Model Context Protocol ecosystem seriously.

If you discover a potential security vulnerability within this project, please follow responsible disclosure guidelines:

1. **Do NOT open a public GitHub issue** to report security vulnerabilities.
2. Email your findings directly to our security maintainers at **`security@mcpaudit.org`** (or create a private GitHub Advisory if available on the repository).
3. Include the following details in your report:
   - Type of vulnerability (e.g., AST bypass, Remote Code Execution, DoS)
   - Step-by-step reproduction instructions or proof-of-concept (PoC) code
   - Affected files and functions
   - Impact assessment
   - Any suggested remediations or patches

---

## Response Timeline

- **Acknowledgment**: Within 48 hours of receipt.
- **Triage & Validation**: Within 5 business days.
- **Patch & Release**: A hotfix will be prepared, verified, and published along with an advisory giving proper credit to the reporter.

Thank you for helping keep the MCP ecosystem secure!
